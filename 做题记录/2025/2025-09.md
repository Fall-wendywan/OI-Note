可以看这个( •̀ ω •́ )[C知道の回答](https://ai.csdn.net/chat/7b656ac6f07141188364827b9ec9573c)

难度：$\textcolor{#45a0de}{蓝}$

不难发现，满足条件的子序列都有一下性质：

1. 若选择了 $a_{i}$ 则不能选 $a_{i + 1}$

2. $|a_i - a_j| \le 2 $ 类似|______|__|的区间中间就是我们的$MEX$
   
   此时后面只能取左端点左边和右端点右边

有了这些性质就可以考虑 $dp$ 了。

**状态：$dp_{j,0/1}$** 表示当前序列的 $MEX = j$ ，且是否包含元素 $j + 1$时的子序列数量。

通过性质应该能够简明地看出来状态设置的原因了。

**转移：**

$\begin{cases}dp_{a_i+1, 0} += dp_{a_i+1, 0} + dp_{a_i, 0}\\dp_{a_i+1, i} += dp_{a_i+1, i}\\dp_{a_i - 1, 1} += dp_{a_i- 1, 0}\end{cases}$

**初始化：**

$dp_{0, 0} = 1
$

最后要给$dp_{0,0}-1$因为不包含空序列。

## 9月24日模拟赛题解

#### 题目描述

一群朋友去度假，有时互相借钱。

例如，爱丽丝为比尔的午餐支付了 $10$ 美元。后来克里斯给爱丽丝 $5$ 美元搭出租车。我们可以假设每笔交易为一个三元组 $(X,Y,Z)$，这意味着第 $X$ 个人借给第 $Y$ 个人 $Z$ 美元。假设 $Alice$，$Bill$ 和 $Chris$ 是第 $0,1,2$ 个人（ $0,1,2$  是他们的 $ID$ ），他们之间的交易可以表示为 $[[0,1,10],[2,0,5]]$。

给定一组人之间的交易清单，返回结算（也就是所有人都还清或收回债务，具体见样例解释）所需的最低交易数量。

#### 输入格式

第一行两个整数 $n,m$  分别表示人数与交易次数。

接下来 $m$ 行每行三个整数 $x_i​,y_i​,z_i$​，表示 $x_i$​ 借给 $y_i$​ 的金额是 $z_i$​。

#### 输出格式

一个整数表示最少交易次数

#### 样例数据

##### input1

```none
3 2
0 1 10
2 0 5
```

##### output1

```none
2
```

##### input2

```none
3 4
0 1 10
1 0 1
1 2 5
2 0 5
```

##### output2

```none
1
```

#### 样例解释

##### 样例1

第 $0$ 个人借给第 $1$ 个人 $10$ 美元 第 $2$ 个人借给第 $0$ 个人 $5$  美元

需要 $2$ 笔交易，其中一种方式是第 $1$ 个人还给第 $0$ 个人和第 $2$ 个人各 $5$ 美元。

#### 数据范围

对于所有数据， $n \le 16,m \le 1000,0 \le x_i, y_i \le n,1 \le z_i \le 1000$

时间限制 1s

空间限制 256MB

简单说一下的话就是考虑前i个武平价值为j体积为k的状态是01的

那么将$dp_{i,j,k}$优化掉有

定义状态：`dp[i][j]` 表示考虑前i个物品时，价值异或和为j的所有可行方案对应的**背包容量集合**（用bitset表示）

- **状态表示**：`dp[i][j]` 是一个bitset<1024>
  
  - bitset的第k位为1 → 存在方案：异或和=j且背包容量=k
  
  - bitset的第k位为0 → 不存在方案
