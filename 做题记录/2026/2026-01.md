[vjudge](https://vjudge.net/contest/781358#problem/A) | 
[luogu](https://www.luogu.com.cn/problem/P4556)

线段树合并板子，带lca、动态开点和权值线段树。
+ 把路径操作变成点差分操作，即 $u + 1, v + 1, lca(u, v) - 1, fa_{lca( u, v )} - 1$。
+ 将子树的桶通过线段树合并到整个树。
+ 通过动态开点的权值线段树存储桶，即对于每个房屋节点u，开一棵权值线段树存储每种救济粮出现的次数。
+ Details of merge:
  + 两个桶都没有值 -> 区间[l, r]都是空节点。
  + 一个有 -> 一个有点，那就直接继承子树（注意懒标记）。
  + 两个都有 -> 区间[l,r]都有点，先递归合并子区间再信息合并上来。
  + 不想破坏原先两个线段树，就得新开。
+ （合并操作）时间上：最坏可以到值域，可证大概是 $O( M \cdot \log(V) )$，其中 $V$ 为值域

一直卡在最后统计答案要第一次扫到的时候存，不然它被合并之后就错了。

### T5 Rikka with Phi

[vjudge](https://vjudge.net/contest/781370#problem/C)

线段树实现上蛮清晰的，然后调了一整个下午？

可以证明对区间取 $\operatorname{phi}$ 的次数上线，于是乎使用tag维护一段连续且相等的区间即可。

然后就发现自己的懒标记线段树写的太烂了，调啊调啊调，吃了15法罚时！

phi 可以背下板子：

```cpp

vector<int> phi(MAXM);
vector<int> prim;
bool is[MAXM];
void euler(){
    for( int i = 0; i < MAXM; i ++ ) phi[i] = i, is[i] = true;
    is[0] = is[1] = false;
    for( int i = 2; i < MAXM;i ++ ){
        if( is[i] )
            prim.push_back( i ), phi[i] = i - 1;
        for( int j = 0; j < prim.size(); j ++ ){
            int p = prim[j];
            if( i * p >= MAXM - 2 ) break;
            is[i * p] = false;
            if( i % p == 0 ){
                phi[i * p] = phi[i] * p;
                break;
            } else phi[i * p] = phi[i] * ( p - 1 );
        }
    }
}
```

### T5 P3195

[luogu](https://www.luogu.com.cn/problem/P3195)

做一下斜率优化模板，但是那天做得太急了，没来得及补充。

首先，根据题意可以得到一个显然的dp，即f[i]表示到第i个玩具装箱的最小费用

（做前缀和优化一下）f[i] = min( j = 1 -> i ){ f[j] + ( i - j - 1 + sum[i] - sum[j + 1] - L ) ^ 2 }

化简，令a[i] = sum[i] + i, b[i] = sum[i] + i + L

变为f[i] = min( j = 1 -> i )

考虑斜率优化，假设在j时比在k时的柿子更优，推得:

懒得敲了，直接粘了：$\frac{(f_j+b_{j+1}^2)-(f_k+b_{k+1}^2)}{(b_{j+1}-b_{k+1})}<2*a_i$

因为左侧与i无关，用斜率优化找到满足条件的用单调队列。

判断用 $slp$ 函数，更新时要更新头、尾，画图可得，如果前面和后面都不优一定不会在后面用到，故单调。

### T2 简单题

[fzoj](http://noj.fzoi.top/d/dx2026/p/P1021)

简单吗？

数数题，第一步就一辈子都想不到了。

发现一个合法的交集一定是一条路径，因为是在树上（即无环）。

然而任何路径都有 $k$ 个点，$k - 1$ 条边。

那么考虑到对于一个点和一条边，计算出经过其的个数之差，就可以算出合法路径的个数。

点是好算的，即过一个点的路径一定是经过两棵子树的，便有式子：

$$
\sum_{u \in E} \sum_{v \in E( u )} siz_v \cdot ( N - siz_v )
$$

然后算路径，发现为 $C_N^2$ 再剪掉两端在同一子树的就做完了。

### T1 宝宝题

[fzoj](http://noj.fzoi.top/d/dx2026/p/P1023) | 
[luogu](https://www.luogu.com.cn/problem/B4161)

题意太阴间了。

操作序列原来指的是给出的操作只取其中的一个区间啊，我还以为是原数组上的一个区间。

挺妙的，就是对于操作我们开一棵线段树，tag1表示当前位置对答案的放大倍数（多次询问后），tag2表示区间本身的放大倍数（不变）

然后就是对于每一个操作区间我们离线下来，从后往前，多次累加tag2直到遇到要加的数。

最后答案就是跑一边然后用tag1累加起来即可。

### T3 luogu P3085

[luogu](https://www.luogu.com.cn/problem/P3805)

学习马拉车。。。

维护 $p_i$ 表示第 $i$ 位最长可以扩展的回文串，发现 $N^2$ 可以优化。

维护 $c, r$ 表示当前最右回文串的中心和右边界。

如果当前 $i$ 落在 $r$ 之内，说明 $i$ 落在以 $c$ 为中心的回文串内。

`j = ( c << 1 ) - i = c * 2 - i`，即镜像出 $p_j$ 的值可以到这里，但是不能超过 $r - i$。

最后更新 $r,c$ 即可。
