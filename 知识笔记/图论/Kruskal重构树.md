# 2025/9/6 krustral重构树

这里只有知识点

解决类似最小生成树的内容

我们把图中两两不在同一个并查集中的点练到一个“虚点”，并让这个虚点的权值为这条边的边权。

当然 我们按照边权大小来操作。

这样，我们就得到了一棵二叉树。

并且有以下特点：

+ 是二叉树

+ 叶子是原来图中的点

+ 非叶子是新点

+ 两点所有路径的最大边权最小=最小生成树两点之间路径的最大值=两点lca点权
