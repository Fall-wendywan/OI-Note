# 树状数组学习笔记

## $\textup{Pt.1 lowbit}$

先讲一下我目前认为树状数组的核心前置。

定义：`lowbit(x)` 表示获取整数 $x$ 在二进制表示中，最低为 1 及后面所有 0 所构成的值。

换句话说，就是保留 $x$ 二进制中最右边的那个 1，将其高位全部变为 0。

计算：`lowbit(x) = x & -x`。

此处说明一下，`-x = ~x + 1`，这样可以使得 `x + ( -x ) = 0`。

即当取反的时候相加应该是全 $1$ 的，那么当加 $1$ 就会溢出然后变成 $0$。

---

## $\textup{Pt.2 维护}$

考虑到任何整数都可以唯一地分解为若干个 $2$ 的幂次之和，

定义 $tr_i$ 处理区间 $[i - lowbit(i) + 1, i]$ 的和。

> 用一个例子进行引入。
>
> 比如 $7 = 4 + 2 + 1$，那么我们所框选的范围就是 $[1, 4], \ [5, 6], \ [7, 7]$。

这样的优势在于将修改和查询的速度平衡了，$tr_i$ 的区间长度就是 $lowebit(i)$。

---

## $\textup{Pt.2 操作}$

参考[这篇文章](https://www.luogu.com.cn/article/8b44awu7)。

**单点修改**时，假定我们修改第 $x$ 个位置。

那么我们找到右端点 $\ge x$ 且包括 $x$ 的区间进行修改即可，而区间长度至少为 $lowbit(x)$。

考虑到第一个满足条件的区间为 $tr_{x + lowbit(x)}$，而根据上述性质，每次增长至少为两倍。

故时间上是 $O(\log N)$ 的。

**区间查询**时，我们将目标区间 $[1, x]$ 转化成查找 $[x - lowbit(x) + 1, x], ...$ 的和。

**区间修改**是容易的，我们将原数组处理成差分数组，按照差分去操作，最后查询的时候查前缀和就可以了。

```cpp
#include<bits/stdc++.h>

using namespace std;
/*
单点修改区间查询板子，不多说了。
*/
const int MAXN = 5e5 + 5;
int N, M;
struct Bit{
    int  tr[MAXN];

    inline int lowbit( int x ){ return x & -x; }

    void mdf( int x, int y ){//给所有包含第x数的区间都加上y
        for( int i = x; i <= N; i += lowbit( i ) )
            tr[i] += y;
    }
    
    int qry( int x ){//查询[1, x]的和
        int ans = 0;
        for( int i = x; i; i -= lowbit( i ) ) ans += tr[i];
        return ans;
    }

}t;

int main(){
    cin >> N >> M;
    for( int i = 1; i <= N; i ++ ){
        int a;
        cin >> a;
        t.mdf( i, a );
    }
    int op, x, y;
    while( M -- ){
        cin >> op >> x >> y;
        if( op == 1 ) t.mdf( x, y );
        else cout << t.qry( y ) - t.qry( x - 1 ) << endl;
    }
    return 0;
}
```

区间修改：
```cpp
#include<bits/stdc++.h>

using namespace std;
/*
区间修改单点查询板子，用差分处理原数组，然后查询就查前缀和即可。
*/
const int MAXN = 5e5 + 5;
int N, M;
struct Bit{
    int tr[MAXN];

    inline int lowbit( int x ){ return x & -x; }

    void mdf( int x, int y ){
        for( int i = x; i <= N; i += lowbit( i ) ){
            tr[i] += y;
        }
    }

    int qry( int x ){
        int ans = 0;
        for( int i = x; i; i -= lowbit(i) ){
            ans += tr[i];
        }
        return ans;
    }
}t;

int main(){
    cin >> N >> M;
    int a, lst = 0;
    for( int i = 1; i <= N; i ++ ){
        cin >> a;
        t.mdf( i, a - lst );
        lst = a;
    }
    int op, l, r, k;
    while( M -- ){
        cin >> op;
        if( op == 1 ){
            cin >> l >> r >> k;
            t.mdf( l, k ), t.mdf( r + 1, - k );
        }
        else{
            cin >> k;
            int ans = 0;
            while( k )//因为是对原数组差分，所以求k的前缀和。
                ans += t.tr[k], k -= t.lowbit( k );
            cout << ans << endl;
        }
    }
    return 0;
}
```
